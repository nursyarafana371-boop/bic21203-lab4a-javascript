Instructions to Run Each Question



Question 1 — Interactive Text Changer



1\. Open the Q1/ folder.

2\. Double-click index.html to open it in a desktop web browser (Chrome, Edge, or Firefox).

3\. Verify the initial paragraph displays "Welcome to my website!".

4\. Click the Change Message button and confirm the text updates to "Hello there!".



Question 2 — Smart Number Validator

1\. Open the Q2/ folder.

2\. Double-click index2.html to open it in a desktop web browser.

3\. Enter test values into the input box and click Check for each case.

4\. Verify the status message below the input displays the corresponding validation result:

&#x09;- Below 10: "The number is lower than 10"

&#x09;- Above 10: "The number is higher than 10"

&#x09;- Equal to 10: "The number is equal to 10"

&#x09;- Empty, whitespace, or non-numeric: "Please enter a valid number!"



Question 3 — Dynamic Number Generator



1\. Open the Q3/ folder.

2\. Double-click index.html to open it in a desktop web browser.

3\. Click the Generate button to display a numbered list from "The number is 1" to "The number is 5".

4\. Click Generate multiple times and confirm the list clears previous items so no duplicates appear.
